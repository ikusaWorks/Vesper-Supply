Vesper Supply — email signatures

Final approved layout, one file per person.

To install:
  1. Click Open to copy — the signature opens on its own page.
  2. Select all (Cmd + A), copy (Cmd + C).
  3. Paste into your mail client’s signature editor.
    Gmail: Settings → See all settings → Signature.
    Outlook: Settings → Mail → Compose and reply → Email signature.
    Apple Mail: Settings → Signatures (untick “Always match my default message font”).

Paste as-is — do not retype. The layout is a table with inline styles, which is what keeps it intact in Outlook and Gmail.
